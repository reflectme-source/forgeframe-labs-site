Localization QA Inspector

Verify the structure of CSV localization files before a game update. The public browser demo is available now. A native Unity Editor version is in development, and is not yet an Asset Store product.

Run the browser demo

CSV input format

Supply UTF-8 text with a key column followed by a source locale and one or more target locales. The default source column is en and can be changed before analysis.

key,en,pl,de
welcome,"Welcome {name}","Witaj {name}","Hallo {name}"
score,"Score: %d","Wynik: %d","Punkte: %d"

Rows may include commas and newlines inside properly quoted cells. The CSV parser accepts escaped double quotes and CRLF/LF line endings.

What the checks mean

CodeMeaning
EMPTY_TRANSLATIONA target language cell is blank.
MISSING_SOURCEThe base-language string is blank.
MISSING_KEYA row has no localization identifier.
DUPLICATE_KEYThe same key appears more than once (case-insensitive).
ROW_WIDTHRow has a different number of cells than the header.
TOKEN_MISMATCHNamed placeholders, printf format codes or markup tag counts differ from the source text.
ICU_REVIEWComplex ICU plural/select syntax needs specialized inspection.

How to use the browser demo

  1. Open Localization QA Inspector.
  2. Select or drop a CSV file up to 2 MB. The file is parsed locally in your browser.
  3. Confirm the source locale, then select Analyze CSV.
  4. Inspect the report. Use Export JSON report to save all findings.
Privacy and safety

The browser tool does not submit your CSV to ForgeFrame Labs. It has no third-party runtime dependencies, login form or analytics. Inspect exported reports before sharing because they contain localization keys and excerpts.

Unity Editor release status

The native EditorWindow is being developed for Unity 2022.3+ and uses a project-local TextAsset. Its C# core has been independently compiled and tested, but a real Unity Editor import, runtime test, package-upload validation and Asset Store review are still outstanding. Do not rely on the native package for production until those steps pass.

Limitations

Structural checks do not guarantee language quality, runtime compatibility, correct pluralization, locale completeness or accessibility. Complex ICU messages should be processed by a dedicated ICU parser. This utility does not automatically rewrite source files.
