How it works

Clear decisions. Reviewable evidence.

The release gate answers three operational questions: did the contract break, was an exception explicitly approved, and which exact inputs produced the decision?

Expiring exceptions

Questions

Before you install

Does this upload our API specification?

No. The comparison happens on your own machine or CI runner. Installing the Action downloads a checksum-verified engine binary from GitHub Releases. You choose whether the resulting evidence is stored in GitHub Actions artifacts.

Is this a runtime contract test?

No. It checks changes in OpenAPI specifications. It cannot detect undocumented runtime behavior, deployment drift or actual consumer impact without additional tests.

Does the report certify audit compliance?

No. The SHA-256 hashes help reviewers match evidence to the original specifications, but do not constitute a digital signature or formal certification.

Why pay for setup when the Action is free?

You pay only for a correctly configured CI workflow, scoped exception policy, verification and handover. The self-hosted tool remains free to use.
