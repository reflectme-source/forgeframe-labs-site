WHAT CONTRACT GUARD DOES

A clear decision for every API change.

Contract Guard uses the open-source oasdiff engine. The additional value is strict exception governance and verifiable release evidence — not a claim to a proprietary breaking-change detector.

Breaks the build on API incompatibility

New required parameters or incompatible responses can fail a pull request before consumers receive the new contract.

Exception policy that expires

An exception needs the exact rule and finding fingerprint, a meaningful reason, and a valid expiration date.

Hash-linked release reports

Store a decision, rule findings, SHA-256 input digests and human-readable summary. Hashes are not digital signatures.

COMMON QUESTIONS

Before you install.

Will my API specification be uploaded?

No. Comparison runs on your GitHub Actions runner or workstation. The Action downloads a checksum-verified oasdiff engine. Uploading the resulting evidence artifact is optional and off by default.

Does it detect all runtime API failures?

No. It analyzes versioned OpenAPI specifications, not undocumented server behavior, production drift or the impact on each actual consumer.

Why pay $149 when the Action is free?

The payment covers professional CI configuration, review policy and verification for one eligible repo. It does not buy access to the open-source detector.

When can I pay?

For supported public repositories, check your OpenAPI file and accept the fixed scope in the browser. If online Checkout is available, Stripe shows the final price and tax before payment. No quote email is necessary.

Which environments are supported?

The composite Action runs on Linux x86_64 with an existing OpenAPI 3.x YAML/JSON contract. Remote external URL references are disabled. Other setups need separate assessment.

Does a report certify legal or security compliance?

No. Reports and input hashes support internal change reviews; they are not independent attestation, legal certification or cryptographic signatures.
