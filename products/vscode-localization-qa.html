Readable diagnostics

Blocking problems and advisory ICU warnings appear in VS Code's Problems panel with helpful explanations.

Jump to the right line

Browse issues by key and language and navigate to the start of the affected logical CSV row, even with quoted line breaks.

Safe report exports

Save priority, key, language, issue and suggested fix in a CSV file. Your original localization file stays unchanged.

Get started

Three steps to your first report.

01 / INSTALL

Add the VSIX preview

Download the release, open VS Code Extensions, choose the menu and select “Install from VSIX”.

02 / INSPECT

Open a localization CSV

Use columns like key, en, pl and de. Run “ForgeFrame Localization QA: Inspect Current CSV” from the Command Palette.

03 / FIX

Review and export

Open Problems, correct blocking issues and export the findings if you want to share them with the team.

This is an early preview. Validate results against your development CSV before depending on them for a production release. The checker detects structural issues; it does not assess translation quality or in-game layout.
