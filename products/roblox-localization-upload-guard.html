Getting started

Three steps, all on your device

  1. Buy on itch.io, unzip the files and install the included .rbxmx into your local Roblox Studio Plugins folder.
  2. Open Plugins → Localization Upload Guard and select the CSV with Studio’s file picker. Test the two bundled sample CSVs.
  3. Correct any blocking rows, rescan, and use Roblox’s official Localization Tools for the actual cloud import.
