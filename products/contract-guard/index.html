CO ROBI CONTRACT GUARD

Jasna decyzja dla każdej zmiany API.

Contract Guard wykorzystuje otwarty silnik oasdiff. Wyróżnia się ścisłą polityką wyjątków i przygotowaniem dowodów wydania — nie deklarujemy własnego silnika detekcji.

Blokada breaking changes

Zmiana wymaganych parametrów lub odpowiedzi API może zatrzymać pull request, zanim nowa specyfikacja trafi do konsumentów.

Wyjątki z datą ważności

Dopuszczalne odstępstwo wymaga dokładnego identyfikatora reguły, odcisku zmiany, uzasadnienia i terminu wygaśnięcia.

Raport z identyfikowalnymi danymi

Zachowaj status decyzji, reguły, ślady SHA-256 i czytelne podsumowanie. Skróty nie są podpisem cyfrowym.

JAK TO DZIAŁA

Od weryfikacji repo do odbioru.

  1. 01

    Opisz środowisko

    Podaj publiczne repozytorium GitHub i ścieżkę pliku OpenAPI. System automatycznie sprawdza specyfikację.

  2. 02

    Akceptacja zakresu

    Sprawdź zakwalifikowany zakres, dane sprzedawcy i warunki realizacji. Zaakceptuj je bezpośrednio na stronie, bez mailowej wyceny.

  3. 03

    Płatność Stripe

    Gdy Checkout jest dostępny, Stripe pokazuje końcową kwotę i podatek. Prace zaczynają się po potwierdzonej płatności i przyznaniu dostępu GitHub.

  4. 04

    PR, testy i odbiór

    W statusie zamówienia zobaczysz PR, wyniki SAFE PASS/BREAKING BLOCK oraz materiały do przeglądu — bez pisania wiadomości o postępach.

PYTANIA I ODPOWIEDZI

Przed instalacją.

Czy to wysyła moją specyfikację?

Nie. Analiza działa na Twoim runnerze GitHub Actions lub lokalnie. Pobierana jest zweryfikowana suma kontrolna silnika oasdiff. Opcjonalny upload artefaktów pozostaje domyślnie wyłączony.

Czy wykrywa wszystkie awarie po wdrożeniu?

Nie. Porównuje zapisane specyfikacje OpenAPI. Nie sprawdza rzeczywistego działania serwera, nieudokumentowanych zachowań ani wpływu na każdego konsumenta.

Dlaczego usługa kosztuje 149 USD, skoro Action jest darmowa?

Płacisz za indywidualną konfigurację CI, polityk i potwierdzenie działania dla jednego kwalifikującego się repozytorium — nie za dostęp do darmowego silnika.

Kiedy można zapłacić?

Publiczne repozytorium sprawdzisz automatycznie, a zakres i warunki zaakceptujesz na stronie. Gdy Checkout zostanie uruchomiony, Stripe pokaże pełną kwotę i podatek. E-mail nie jest wymagany. Dane kart przetwarza Stripe.

Jakie środowiska obsługujecie?

Wersja Action obsługuje Linux x86_64 i istniejącą specyfikację OpenAPI 3.x w YAML/JSON. Zewnętrzne referencje URL są wyłączone. Niestandardowe konfiguracje wymagają osobnej analizy.

Czy raport poświadcza zgodność regulacyjną?

Nie. Raport i skróty SHA-256 służą do wewnętrznej weryfikacji zmian. Nie są niezależnym atestem, podpisem elektronicznym ani certyfikatem bezpieczeństwa.

Masz repozytorium z OpenAPI?

Pokaż nam wymagania techniczne. Wstępna kwalifikacja nie jest zamówieniem i nic nie kosztuje.
