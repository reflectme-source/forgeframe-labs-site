Kwalifikacja i zamówienie

Automatyczny zakup obejmuje jedno publiczne repozytorium GitHub z dostępnym plikiem OpenAPI 3.x YAML/JSON, ze scaloną specyfikacją bez referencji do innych plików lub adresów URL oraz standardowy GitHub Actions Linux x64. System sprawdza publiczny plik przed przejściem do płatności. Repozytoria prywatne i nietypowe środowiska nie kwalifikują się do automatycznego zakupu.

Cena i podatki

149 USD jednorazowo za jedno kwalifikujące się repozytorium, bez subskrypcji. W zależności od lokalizacji i statusu podatkowego nabywcy mogą wystąpić podatki. Stripe musi wyświetlić należny podatek i ostateczną kwotę przed zatwierdzeniem płatności. Weryfikacja zgodności repozytorium jest bezpłatna.

Zakres usługi

Pull request z konfiguracją kompatybilności OpenAPI w CI, poprawnym porównaniem wersji bazowej, zasadami wyjątków, rzeczywistym testem SAFE PASS oraz BREAKING BLOCK, dowodami i instrukcją obsługi. Sama GitHub Action pozostaje darmowa.

Dostęp i termin

Prace zaczynają się dopiero po potwierdzonej płatności Stripe i przyznaniu przez klienta dostępu do konkretnego repozytorium w natywnym systemie GitHub. Nie wysyłaj haseł ani tokenów e-mailem. Planowany termin to do 10 dni roboczych od potwierdzenia płatności i dostępu; opóźnienia klienta w udzieleniu dostępu lub przeglądzie PR mogą wpłynąć na harmonogram. Informacje o istotnych odstępstwach udostępniamy w statusie zamówienia i poprzez podany kontakt.

Poza zakresem

Tworzenie API lub SDK, rozwiązywanie zewnętrznych referencji, niestandardowe runnery, hosting, panel SaaS, testowanie działającego API, abonament czy samodzielne wdrożenie produkcyjne. Dostarczamy PR do zatwierdzenia; nie łączymy zmian do produkcji bez zgody.

Anulowanie, brak możliwości realizacji, zwroty

Jeżeli zamówienia nie można zrealizować w uzgodnionym zakresie, organizujemy odpowiedni zwrot na pierwotną metodę płatności. Anulowanie przed rozpoczęciem prac zasadniczo uprawnia do pełnego zwrotu. Po rozpoczęciu prac zakres zwrotu zależy od wykonanej usługi i obowiązujących przepisów. Postanowienia nie ograniczają bezwzględnie obowiązujących praw konsumentów. W przypadku anulowania lub wady skontaktuj się przez forgeframe.lab@gmail.com z numerem zamówienia.

Prywatność i status

Przetwarzamy niezbędne dane kontaktowe, dane firmy, ścieżkę do publicznego repozytorium i identyfikatory płatności. Dane karty obsługuje Stripe. Nie przesyłaj prywatnych specyfikacji ani sekretów. Status w tej samej przeglądarce działa poprzez lokalny identyfikator sesji; po jego utracie można skontaktować się z pomocą, podając numer zamówienia. Zobacz politykę prywatności ForgeFrame Labs.

Zakup konsumencki — informacja o dostępności

Opcja zakupu prywatnego jest przygotowywana i obecnie nie przyjmuje płatności. Zamówienia konsumenckie zostaną dopuszczone dopiero po zatwierdzeniu zasad podatkowych dla kraju klienta, prezentacji wymaganej prawem ceny końcowej oraz warunków konsumenckich. Przed płatnością klient otrzyma informacje o ustawowym prawie odstąpienia i zwrotach. Jeżeli konsument wyraźnie poprosi o rozpoczęcie usługi przed upływem 14-dniowego terminu odstąpienia, otrzyma informacje o ewentualnym proporcjonalnym wynagrodzeniu za rozpoczęte prace i utracie prawa odstąpienia dopiero po pełnym wykonaniu usługi, gdy ma to zastosowanie. Ta informacja nie ogranicza bezwzględnie obowiązujących praw konsumenta.

Akceptacja

Zatwierdzenie Checkout po zaznaczeniu wymaganych oświadczeń oznacza przyjęcie ustalonego zakresu i warunków. Dopiero potwierdzenie płatności przez Stripe kwalifikuje zamówienie jako opłacone. Odbiór usługi następuje po przekazaniu PR oraz dowodów PASS/BLOCK.
