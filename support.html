Reporting an issue

Describe a specific failure so we can reproduce it. Helpful reports save time for both sides and make fixes more reliable.

Please don't email API keys, passwords, confidential customer records or full private source files.

  • Name the product and platform (Apify, browser, Unity, Roblox or IDE).
  • Include the relevant version, expected behavior and what occurred instead.
  • Provide minimal reproducible steps and sanitized example data if necessary.
  • For OTOMOTO monitoring, specify whether it was a first baseline scan or a later comparison.
